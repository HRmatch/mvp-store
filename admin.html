Configurações

Conecte o admin ao seu repositório GitHub para salvar alterações automaticamente.

Conexão com GitHub

As credenciais são salvas apenas no seu navegador (sessionStorage) e nunca enviadas a terceiros.

Crie um token em github.com/settings/tokens com permissão repo → Contents → write.

Como publicar o site

  1. Crie um repositório público no GitHub.
  2. Faça upload dos arquivos index.html, admin.html e products.json.
  3. Vá em Settings → Pages e ative o GitHub Pages na branch main.
  4. Seu site estará em https://seunome.github.io/repositorio.
  5. Configure as credenciais acima e gerencie tudo por aqui.
